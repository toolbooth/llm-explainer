# arXiv Endorsement 请求邮件草稿(发布后使用)

机制备忘:2026-01 新政后所有首投者需 endorsement。流程:开始 arXiv 提交
→ 生成 endorsement code → 在相关论文摘要页底部 "Which of these authors are
endorsers?" 找人 → 发邮件附 code。目标分类 **cs.CY**(明文含 "computers
and education"),cs.HC 交叉。时机:**文章上线后**(活链接是最强说服物)。
候选:Transformer Explainer 作者(Cho/Chau, Georgia Tech Poloclub)、
CNN Explainer 作者(Wang)、VISxAI 历届作者——都是我们引用的人。

**发送前须personalize的位置用〔〕标出。每封都要你亲笔调整语气。**
